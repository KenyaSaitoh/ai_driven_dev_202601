## サポートされる操作の例

### 基本操作

| 操作 | 説明 | 例 |
|------|------|-----|
| ページを開く | 指定URLでページを開く | `http://localhost:5173/` |
| 入力 | テキストボックスに値を入力 | メールアドレス → `user@example.com` |
| クリック | ボタンやリンクをクリック | ログインボタン |
| 選択 | セレクトボックスで値を選択 | カテゴリ → `カテゴリID 2` |
| 確認 | 要素のテキストや状態を検証 | URL → `/books` に遷移 |

### 待機操作

| 操作 | 説明 | 例 |
|------|------|-----|
| 待機 | 要素の読み込み完了を待つ | カテゴリ選択肢 → 読み込み完了を待つ |

重要: セレクトボックスの選択肢がAPIから非同期に読み込まれる場合、「待機」ステップを追加してください。

例：
```markdown
| 12 | 待機 | カテゴリ選択肢 | 読み込み完了を待つ | APIから取得 |
| 13 | 選択 | カテゴリ | 最初の選択肢（すべて以外） |  |
```

### ダイアログ操作

| 操作 | 説明 | 例 |
|------|------|-----|
| ダイアログ受諾 | 確認ダイアログでOKをクリック | OKをクリック |
| ダイアログ却下 | 確認ダイアログでキャンセルをクリック | キャンセルをクリック |

注意: ダイアログ処理はシンプルに保ってください。「キャンセル→再試行」のような複雑なフローは避けることを推奨します。
